# Sharayu Mhaske — Portfolio Website

A responsive, single-page portfolio website based on the resume provided.

## Run it locally
1. Extract the ZIP file.
2. Open `index.html` in any modern browser.

No build tools or package installation are needed.

## Publish it for free with GitHub Pages
1. Sign in to GitHub and create a repository named `sharayumhaske22.github.io` (or use any repository you prefer).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish your site. Your URL will be shown in the Pages settings.

## Before publishing
- Verify the LinkedIn URL and phone number.
- Add a real GitHub profile/repository link once confirmed.
- Add project photos, code links, and a demo only where you have them.
- The resume lists a Task Management System, but its technology stack and repository were not provided; this portfolio currently prioritizes the documented Arduino projects rather than inventing implementation details.
- If you have a PDF resume, you can add it as `resume.pdf` and place a download link in the hero section.
